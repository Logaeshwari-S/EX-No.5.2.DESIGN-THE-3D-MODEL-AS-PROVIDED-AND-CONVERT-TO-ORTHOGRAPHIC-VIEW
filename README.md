# EX No.5.2.DESIGN THE 3D MODEL AS PROVIDED AND CONVERT TO ORTHOGRAPHIC VIEW
## DATE:

## AIM: 
To create orthographic view of given 3D model

## REQUIREMENTS: 
1. Autodesk fusion 360
2. Windows 10
3. 16 GB of RAM (integrated graphics recommend 1 GB or more)
4. 2.5 Mbps or faster download; 500 Kbps or faster upload 

## PROCEDURE:

1.To create the base component first click the create sketch option and draw a rectangle of 30mm * 30mm.

<img width="447" height="330" alt="image" src="https://github.com/user-attachments/assets/84d8d216-50e4-4ff7-8481-1cacc2417f63" />

<img width="376" height="410" alt="image" src="https://github.com/user-attachments/assets/e7b9ba2e-5ded-44b0-9556-baa4d006293f" />


2.Now to create small slots at the each corner draw four small rectangle of 2mm * 2mm at each corner.
<img width="690" height="692" alt="image" src="https://github.com/user-attachments/assets/81d24d8c-3d3d-4455-acce-ec9521f1ba6f" />

3.Now extrude only the  bigger rectangle not the slots by 4 mm while extruding the sketch choose new component option.

4.Give color to the component by choosing appearance option and name the component as base.

<img width="852" height="783" alt="image" src="https://github.com/user-attachments/assets/cf12510f-1d4c-43f5-9434-f81e3132c299" />

5.Now select the back view of the component and give create sketch.

6.Draw the same rectangle slots of 2mm *2mm.now extrude it by 1.5mm.

<img width="1062" height="611" alt="image" src="https://github.com/user-attachments/assets/acf9ce0a-d161-4aff-b991-703c25e7bb19" />


7.Now hide this component.
8.choose front view and give create sketch.
9.To make a rectangle leg draw a rectangle of length and breadth 30mm * 2mm.
<img width="757" height="711" alt="image" src="https://github.com/user-attachments/assets/d2468e66-f678-40e4-8e43-7ff0c99b9301" />

10.Extrude the rectangle by 2mm while extruding choose new component option.

11.Give color to the leg by choosing appearance option. 
<img width="726" height="688" alt="image" src="https://github.com/user-attachments/assets/49548d62-3084-4616-ab54-a8ccb1e7907f" />

12.Now using copy paste option, copy that legs into four.
<img width="918" height="682" alt="image" src="https://github.com/user-attachments/assets/82cbeeaf-792a-4b1f-9b73-c2bb6f367eb2" />

13.Make the base component visible.
14.Using join option, join the legs and base together as it looks like a chair.
<img width="1045" height="742" alt="image" src="https://github.com/user-attachments/assets/4349fb71-6ba3-4ec0-b5c0-971cbc32f1dd" />
